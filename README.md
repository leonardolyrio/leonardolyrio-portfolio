Este é o meu portfólio profissional, desenvolvido para demonstrar minhas habilidades em engenharia de software, design de interface e otimização de performance. O projeto foi construído com foco em proporcionar uma experiência de usuário fluida, moderna e extremamente rápida.

## 🛠 Tech Stack

- **Frontend**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Estilização**: [Tailwind CSS](https://tailwindcss.com/)
- **Animações**: [Framer Motion](https://www.framer.com/motion/)
- **Smooth Scroll**: [Lenis](https://github.com/darkroomengineering/lenis)
- **Linguagem**: [TypeScript](https://www.typescriptlang.org/) (Tipagem rigorosa)

---

## 🚀 Destaques de Engenharia

Mais do que um site visual, este projeto aplica conceitos avançados de arquitetura frontend para garantir a melhor experiência possível:

### ⚡ Performance & Otimização
- **Code Splitting**: Implementação de `React.lazy` e `Suspense` para carregamento sob demanda de rotas, reduzindo drasticamente o tamanho do bundle inicial e melhorando o *First Contentful Paint* (FCP).
- **Assets Otimizados**: Uso de imagens em formato `.webp` para reduzir o peso total da página sem perda de qualidade.

### 🔍 SEO & Visibilidade
- **Metadados Estratégicos**: Configuração completa de meta-tags e protocolos **Open Graph**, garantindo que o site seja indexado corretamente por motores de busca e exiba pré-visualizações ricas em redes sociais.
- **Semântica HTML**: Uso rigoroso de tags semânticas para melhorar a indexação e a acessibilidade.

### 🎨 Experiência do Usuário (UX)
- **Smooth Scrolling**: Integração do Lenis para proporcionar uma navegação fluida e orgânica.
- **Animações Reativas**: Uso de `whileInView` do Framer Motion para criar revelações de conteúdo dinâmicas enquanto o usuário navega.

### 🛡️ Qualidade de Código
- **Type Safety**: Base de código totalmente tipada com TypeScript, eliminando erros comuns em tempo de execução e facilitando a manutenção.
- **Arquitetura Modular**: Separação clara entre páginas, seções e componentes reutilizáveis.

## 💻 Como rodar o projeto localmente

### Pré-requisitos
- [Node.js](https://nodejs.org/) instalado (versão 18 ou superior)
- [npm](https://www.npmjs.com/)

### Passos
1. Clone o repositório:
   ```bash
   git clone https://github.com/leonardolyrio/leonardolyrio-portfolio.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd leonardolyrio-portfolio
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
5. Acesse `http://localhost:5173` no seu navegador.
